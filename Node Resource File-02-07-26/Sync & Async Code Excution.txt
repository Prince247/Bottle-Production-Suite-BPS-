Sync and async version
 
function run() {
console.log(1);
 
let data = bigFunctionSync(); // blocks thread (5 sec)
 
console.log(data);
console.log(2);
}
 
console.log("A");
run();
console.log("B");
 
A → 1 → (wait 5 sec) → data → 2 → B
 
❌ Everything is blocked
❌ Even "B" waits
 
Async version
async function run() {
console.log(1);
 
let data = await bigFunctionAsync(); // waits ONLY here
 
console.log(data);
console.log(2);
}
 
console.log("A");
run();
console.log("B");
 
A → 1 → B → (after 5 sec) data → 2
✔ "B" did NOT wait
✔ Thread is FREE to do other work
 
Sync
Blocks whole thread
App becomes slow
No parallel work
Other tasks continue
 
Async (with await)
Blocks only that function
App stays responsive
Other tasks continue
 
Example
 
async function run() {
  console.log(1);
  return await bigFunctionAsync(); // (1)
}
 
async function main() {
  console.log("A");
 
  let data = await run(); // (2)
 
  console.log("B:", data.value);
}
Op-
A
1
(after ~5 sec delay)
B: value
 
main() waiting for run()
run() waiting for bigFunctionAsync()
