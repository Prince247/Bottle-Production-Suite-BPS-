Optimizations
When an API takes a long time, it usually happens for two reasons: 
-> 1) A single task itself is time-consuming or taking long time
-> 2) A task that itself takes significant time but executed multiple times.

1. I used Attributes in Sequelize to fetch only required columns instead of full table data, which improved performance
2. Breaking the work using Splitting Heavy API,not major time reduced, But it improves user experience and UI gets faster response initially
3. Pagination - means fetching data in parts instead of all at once, Faster API
Instead of 10,000 rows
Send 50 per request 
👉 OFFSET means:skip first N rows, then take LIMIT
LIMIT 50 OFFSET 0 -> OFFSET 0 → skip none → start from 1
LIMIT 50 OFFSET 50 -> OFFSET 50 → skip first 50 → start from 51
4. Indexing - Improves SELECT performance, Slightly slows INSERT/UPDATE
5. Views vs Materialized Views
✅ View:
Just a saved query
Runs every time → slower
“View does not store data, it executes query each time.”
✅ Materialized View: Materialized view stores data physically in the database, unlike normal views.
Stores actual data (like table)
Faster reads
REFRESH MATERIALIZED VIEW view_name;
